Ping

The request we send to you periodically and whenever there are new changes.

Request

POST
Any URL of your choosing

Headers

HTTP header Description 
X-Signature: 17FUWCstyodDzsCkG5/gU/2VA2vUEcHfvFxGh8RCElo=
 Base64 encoded HMAC-SHA2-256 signature of the body signed with your API key.

Fields

JSON field Description 
{% include "code/ping-shopid.json" %}
 The shopid this ping is for. 
{% include "code/ping-seq.json" %}
 The current maximum seq value.

We send you this ping request whenever a new change is ready to be fetched, as well as periodically in case a ping has been missed. When you reveive the ping request you can verify its authenticity using the X-Signature header. Afterwards you can use the seq value to determine if there are any changes to be fetched.
