Synchronization

They typically use webhooks, which is to say that when a shop receives a new transaction, they send a request to a URL of your choosing containing the data for the new transaction, i.e. they push data to you. What we do instead is invert the process. Rather than us pushing the data to you, you are responsible for pulling the data from us. Synchronization, in general, is an extremely complicated problem and the length of this document does not reflect any unique complexity inherent in our system. So please don’t be put off, this page and the next are all you need to get started, and you can read why we designed it like this in the FQA.
