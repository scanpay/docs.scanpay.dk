Payment Links

Payment links are unique, shareable URLs that direct customers to our hosted payment page, where they can securely enter their payment details. While a payment link can be shared and accessed multiple times, it can only be used for a single payment. The link remains active for a limited time, as specified by the lifetime field. Additionally, you can manually expire a payment link at any time using the expire API request.
