Payment Links

Payment links are unique, shareable URLs that direct customers to our hosted payment page, where they can securely enter their payment details. While a payment link can be shared and accessed multiple times, it can only be used for a single payment.

Lifetime

Payment links have a limited, user-defined lifespan. The lifespan of a payment link can be defined in the lifetime parameter when creating. The lifespan of a payment link provides a hard limit on when a payment can be submitted, meaning if the payer has not completed all authentication before the time limit the payment will be rejected. Payment links can also be immediately expired.

Payment window

The payment window is designed to be responsive and works on all devices.
