Expire payment link

Manually expire a payment link. The link will no longer be valid, and the customer will not be able to pay.

Request

POST
https://api.scanpay.dk/v2/{shopid}:pay:{payid}/expire
  • payid is the ID you received when creating the payment link.

The request has no body. The response has no defined fields and as such is an empty JSON object.
