Expire payment link

Use this API to expire a payment link.

{% include "tpl/v2-warning.html" %}

Request

The request endpoint is: https://api.scanpay.dk/v1/expire/$payid

Request Headers

HTTP header Description
Authorization: Basic base64_encode($apikey) HTTP basic authentication with your API key as credentials, which you will need to base64 encode.

Request Fields

JSON fields Description

Request Requirements

The API is fault-tolerant and forgiving. Apart from items, all fields are optional, and we will ignore them if they are invalid. There is a maximum request size of 32 kB but no field size restrictions.

Response

Link Parameters

The following link parameters can be appended to the payment link:

Link parameter Description
?go=mobilepay Redirect the customer to MobilePay Online. You need to enable MobilePay Online here.

Errors

You can receive the following errors when you create payment links:

Code HTTP Body Description
400 invalid json Invalid JSON.
403 invalid apikey Invalid API key.
408 Request Timeout The request timed out after 8 seconds.
413 Request Entity Too Large The request body was larger than 32 kB.
400 Request Header Or Cookie Too Large The request HTTP headers were larger than 4 kB
500 internal server error Technical issue at Scanpay. Please try again later.
