Void transaction

After a payment has been authorized, the payment is not complete until it has been captured. If you do not wish to capture the payment, you can void it using the void API described below. You can void a transaction with the void API request. However, you can only void transactions that are not yet captured, and you cannot undo a void.

{% include "includes/v2-warning.html" %}

Request

POST
https://api.scanpay.dk/v2/$shopID:trn:$trnID/void
  • $shopID is a unique ID for the shop. You can find it here.
  • $trnID is the transaction ID. You receive this in the Synchronization API.

Request Headers

{% include "includes/code/basic-auth.html" %}
HTTP headers Description

Request Body

The request body must be empty.

Response

Success

Successful requests return status code 200 and an empty JSON object.

Errors

Failed requests return an HTTP error code and an error message in the HTTP body:

Code HTTP Body Description
400 invalid json Invalid JSON.
403 invalid apikey Invalid API key.
408 Request Timeout The request timed out after 8 seconds.
413 Request Entity Too Large The request body was larger than 32 kB.
400 Request Header Or Cookie Too Large The request HTTP headers were larger than 4 kB
500 internal server error Technical issue at Scanpay. Please try again later.
