Capture transaction

With the capture API request, you can perform full or partial captures on a transaction. You can perform multiple captures on a transaction but cannot capture more than the authorized amount.

Request

POST
https://api.scanpay.dk/v1/$trnID/capture
  • $trnID is the transaction ID. You receive this in the Synchronization API.

HTTP headers Description

Request Body

JSON fields Description
"total": "199.95 DKK" The amount to capture.
"index": 0 The number of actions performed on the transaction. This is used to prevent duplicate captures. 
{% include "docs/transactions/code/items.json" %}

An optional array of captured items (specs). This is only metadata, and it does not affect the actual capture. Invalid data will be discarded without returning an error.

We display the captured items in our dashboard.

Response

Success

Successful capture requests return status code 200 and an empty JSON object.

Errors

Failed capture requests return an HTTP error code and a error message in the HTTP body:

Code HTTP Body Description
400 invalid json Invalid JSON.
400 invalid total Invalid or missing total field.
403 invalid apikey Invalid API key.
408 Request Timeout The request timed out after 8 seconds.
413 Request Entity Too Large The request body was larger than 32 kB.
400 Request Header Or Cookie Too Large The request HTTP headers were larger than 4 kB
500 internal server error Technical issue at Scanpay. Please try again later.
