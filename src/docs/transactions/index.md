# Transactions

A transaction is a payment that has been [authorized][states]. You can
create a transaction through a [payment link][new] or [subscriber
charge][charge]. Transactions can be [captured, refunded, or
voided][states]. Transactions can be partially authorized, captured, or
refunded, but not partially voided.
