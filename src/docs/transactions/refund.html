Refund transaction

With the refund API request, you can perform full or partial refunds on a captured transaction. You can perform multiple refunds but cannot refund more than the captured amount.

Request

POST
https://api.scanpay.dk/v2/$shopID:trn:$trnID/refund
  • $shopID is a unique ID for the shop. You can find it here.
  • $trnID is the transaction ID. You receive this in the Synchronization API.

Request Headers

HTTP headers Description
Authorization: Basic base64_encode($apikey) HTTP Basic authentication. Read more.

Request Body

JSON fields Description
"total": "199.95 DKK" The amount to refund.
"index": 1 The number of actions performed on the transaction. This is used to prevent duplicate refunds. 
{% include "docs/transactions/code/items.json" %}

An optional array of refunded items (specs). This is only metadata, and it does not affect the actual refund. Invalid data will be discarded without returning an error.

We display the refunded items in our dashboard.

Response

Success

Successful requests return status code 200 and an empty JSON object. 

{} Response JSON
HTTP 200 OK
{}

Errors

You can receive the following errors:

Code HTTP Body Description
400 invalid json Invalid JSON.
400 invalid total Invalid or missing total field.
403 invalid apikey Invalid API key.
408 Request Timeout The request timed out after 8 seconds.
413 Request Entity Too Large The request body was larger than 32 kB.
400 Request Header Or Cookie Too Large The request HTTP headers were larger than 4 kB
500 internal server error Technical issue at Scanpay. Please try again later.
