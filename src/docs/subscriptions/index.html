Subscriptions

The Subscriptions API allows you to handle recurring payments. You can use it to charge customers on a regular basis or to save a customer's payment details, so the customer does not have to enter the information again.

Subscribers

Our API only tracks subscribers and not their individual subscriptions. You are responsible for charging the correct amount at the correct time. You should only create one subscriber per person and instead renew subscribers whose payment details have expired or have left and come back, rather than create new ones.
