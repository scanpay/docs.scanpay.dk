Charge Subscriber

The charge subscriber API call will charge a specified subscriber ID.

Request

POST
https://api.scanpay.dk/v1/subscribers/$subID/charge
  • $subID is the subscriber ID. You receive this in the Synchronization API.

Request Body

JSON fields Description
"orderid": "123" A unique ID that you choose. Never reuse IDs or your synchronization may behave in unexpected ways. 
{% include "docs/subscriptions/code/items.json" %}
 An array with items.
  • name: The name of the item.
  • quantity: The number of items (integer).
  • total: The line total (i.e. unit-price x quantity) with an ISO 4217 currency code. This is required.
  • sku: A SKU for this particular product.
In this example the grand total is 13397.9986 DKK. Most acquires only support 2 digits after the decimal point. If this is the case we will truncate to 13397.99.

Note that if the billing address and/or shipping address is unspecified, they will default to the addresses specified in the subscriber.


Customer billing and shipping address.
  • name: The full name.
  • company: Legal company name.
  • vatin: EU VAT identification number.
  • gln: Global Location Number or European Article Numbering (EAN-number).
  • email: E-mail address.
  • phone: Phone number with country prefix.
  • address: An address array where each element is a new line.
  • zip: Postal code.
  • city: City.
  • state: State or region.
  • country: Two-letter country code (ISO 3166-1).
"autocapture": true Automatically capture the payment. Default is true.

Response

The HTTP response headers will contain the following headers:

HTTP headers Description
Idempotency-Status: OK Response header to ensure that the idempotency key has been considered.

Success

Successful charge requests return status code 200 and an empty JSON object.

Errors

Failed charge requests return an HTTP error code and a error message in the HTTP body:

Code HTTP Body Description
400 invalid json Invalid JSON.
400 invalid total Invalid or missing total field.
403 invalid apikey Invalid API key.
408 Request Timeout The request timed out after 8 seconds.
413 Request Entity Too Large The request body was larger than 32 kB.
400 Request Header Or Cookie Too Large The request HTTP headers were larger than 4 kB
500 internal server error Technical issue at Scanpay. Please try again later.
